# The Ridge | Reserve Shelf

A compact, interactive staff-learning demo for the reserve whiskey list at The Ridge by Mill House.

The app is a self-contained static page in `index.html`; it has no build step or external runtime dependencies.

## Publish with GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. The workflow in `.github/workflows/pages.yml` will publish the site after each push to `main`.

Once the first deployment finishes, the site will be available at:

https://chipnesser.github.io/ridge-reserve-training/

Menu entries and bottle details should be checked against the restaurant's current list and bottle labels before using this as formal staff training.
